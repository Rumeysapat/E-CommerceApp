🛍️ E-Commerce App

Bu proje, basit bir JavaScript tabanlı e-ticaret uygulamasıdır.
Kullanıcılar ürünleri görebilir, sepete ekleyebilir, sepet miktarını görebilir ve veriler Local Storage üzerinde saklanır.
Veriler db.json dosyasından fetch API ile çekilir.

🚀 Özellikler

📦 Ürünleri db.json üzerinden dinamik olarak yükler

🛒 Ürünleri sepete ekleme

🔢 Toplam ürün sayısını hesaplama

💰 Toplam fiyat hesaplama (500 ₺ altı için +100 ₺ kargo eklenir)

💾 Verileri Local Storage’da saklama

🧭 Basit menü aç/kapa (responsive destekli)
